# 桌面玻璃分组 0.2.0 Implementation Plan

**目标：** 提供本机 Windows 原生桌面的 `0.2.0-win-x64` 安装体验包，支持独立玻璃分组、普通桌面项目 Hidden 收纳及原位恢复。

**设计：** [设计基线](mvp-design.md)。**验收：** [当前验收记录](acceptance.md)。本机体验包的功能、构建、隔离安装卸载和独立审查门禁已通过；未测试场景和早期系统设置收尾见下方。

**执行方式：** 主代理集成与交付，组件和租约分包实施，未参与实施的 Reviewer 只读审查。复用 `feat/desktop-groups-mvp`，不推送、不创建 PR、不合并。临时证据及产物仅在 `.codex/`，正式文档在 `docs/`。

## 约束

- 一组一窗口，组件外原生输入，不铺全屏输入层、不隐藏整张列表、不注入 Explorer。
- 只暂借收纳项的 Hidden 位，不移动文件；日志先持久化、guard 就绪后才修改属性。
- 恢复按稳定身份核对，属性优先于坐标；失败保留责任并阻止卸载清理。
- 实际桌面显示隐藏项及自动排列必须关闭；程序不代改设置，无法确认状态时拒绝收纳。
- 外屏临时回退不覆盖保存偏好；未实测能力明确注明。

### Review Focus

1. 接管失败或主进程退出，原图标是否恢复；窗口句柄复用是否影响其他窗口。
2. 外屏断连时是否覆盖原位置；同屏型号或接口改变是否错误匹配。
3. 新文件、虚拟 Shell 入口和失效快捷方式是否仍可访问。
4. 数据损坏、程序多开、运行中卸载是否丢失用户数据。
5. 清理是否严格限制软件拥有目录；图标及 GDI/COM 资源是否释放。
