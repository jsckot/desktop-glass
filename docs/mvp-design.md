# 桌面玻璃分组 MVP 设计

2026-10-22，状态：按会话授权实施。仅首轮适配 Windows 11 26H2 / 26300.9711 x64。

## 范围与体验

提供分组创建、重命名、移动、缩放、透明度及圆角设置、入口拖拽和排序、双击打开、布局锁定；玻璃卡片使用壁纸采样模糊、半透明底色和边缘高光，不使用持续动态折射。应用图标保持原样。任务栏、文件夹图标重绘、搜索和其他 Windows 版本认证留待体验后决定。

分组仅保存入口引用，不移动原文件。启用整理时，枚举全部桌面 Shell 项目并显示未分类项目，再临时隐藏原生桌面图标视图。不改文件属性、注册表桌面可见性或原图标位置。托盘提供打开设置、刷新、恢复并退出。原生桌面右键操作可通过打开桌面目录完成；MVP 的空白处右键菜单提供新建分组和打开桌面目录。

桌面宿主为 Explorer 桌面视图同层的子窗口，避免占据普通应用窗口层；接管失败时保留原生桌面并报告错误。若 Explorer 重建，主进程释放旧宿主、恢复可见性，要求重新启动整理，不向 Explorer 注入代码。

## 多屏与数据安全

按显示器设备身份保存 DIP 坐标。显示器序号不作持久身份；匹配歧义时不覆盖旧记录。外屏断开后的临时收纳不写回原位置；重新连接恢复。主屏已有分组不挪动；缺屏内容进入独立滚动收纳面板。工作区变小只调整呈现位置，不修改保存的偏好。

配置使用版本化 JSON、同目录原子替换和上一份有效备份。损坏配置保留并报错，不以空配置覆盖。退出不删除用户内容。恢复辅助进程先就绪后隐藏，监控主进程退出，使用 Explorer 进程身份验证原窗口后恢复。持久日志早于隐藏；崩溃后下次启动检查并恢复。若不能确认可恢复，不启动桌面接管。

## 安装与资源

按用户安装到 `%LOCALAPPDATA%/Programs/DesktopGlass`，配置在 `%LOCALAPPDATA%/DesktopGlass`。自包含 x64 发布不要求用户安装运行库。不自动开机启动。提供卸载入口，恢复桌面后清理仅属于本工具的文件和配置，保留用户真实文件。程序未签名，签名与系统信任提示不是本轮功能。

单屏常态私有内存目标 150 MiB 内、双屏 200 MiB 内，空闲整机 CPU 目标 <0.5%；以实际测量报告为准。没有持续动画；图标缓存有界；显示变更防抖，文件变化触发更新。

## 验收

领域测试覆盖分类引用、移动排序、屏幕断开重接、负坐标、混合 DPI、工作区缩小、损坏配置及重复恢复。Windows 集成检查覆盖桌面宿主能力、图标读取、正常退出和主进程强制终止恢复。真实外屏热插拔、主屏切换和睡眠恢复必须明确标注实测与未测。交付可安装包、构建测试结果、已知限制，并完成独立只读审查；审查不可用时标记待独立审查。
