首次安装不自动创建组件；从 v1 升级时保留并暂停已有分组一次，随后启动恢复持久显示意愿。缺屏分组不在主屏堆叠。临时前景状态不保存，重启仍贴在桌面。

松手闪烁的根因是每次提交几何后关闭并重建全部组件。当前同屏提交仅更新已有 HWND；红/绿诊断分别证实此前会重建、修正后复用。跨显示器或 DPI 仍重建宿主。

## 本轮已确认的体验

- 使用独立玻璃分组，组件外保留 Windows 原生桌面。用户已确认组件可见、标题拖动和组件外操作正常。

## 发布前发现并修正的问题

1. 全局隐藏显示缓存与实际桌面视图可能不同步。收纳改为严格检查实际 ViewOptions 的 S_OK、非空及关闭状态，全局值仅作诊断；增加回归，未知或实际开启仍拒绝。
2. 动态图标枚举过程中可能发生索引 `E_BOUNDS`。仅该索引错误触发最多三轮完整重启；持续变化明确失败，其他错误仍透传，不把不完整枚举当作图标不存在。
3. 强退恢复使用按 ID 打开的属性句柄，本机实验显示其目录属性事件在句柄关闭后才发出。改为关闭非借用的恢复句柄后再发送原 Shell 通知，原身份、位置和日志校验保持。真实发布版的正常/强退验证随后通过。

无效的 Shell 预热候选已撤销，失败证据保留；没有延长恢复超时或放宽成功条件。
