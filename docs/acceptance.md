## 用户体验反馈与验收纠正

2026-10-22：用户安装后仅看到壁纸及本程序右键菜单，分组和图标未显示；新建分组也没有可见变化。用户进一步明确必须保留 Windows 原生桌面交互，只增加局部分组组件，并在退出后将收录图标原位还原。旧全屏接管方案不满足该要求。

原 ui-test 的 Passed 条件是退出后原生图标视图恢复；内部用 VisualBrush 生成离屏图片，没有检查实际桌面合成。本次隔离重跑仍报告 Passed=true（.codex/tmp/desktop-visibility/baseline.json），不能作为显示正常或缺陷修复的证据。保留下述历史检查结果，同时撤回它们足以支持真实桌面 UI 验收的判断。新版必须通过更新后的设计验收，当前尚未修复或重新发布。

只读 Shell 探针已在本机完成（.codex/tmp/native-desktop-probe/probe.log）：桌面访问链及 IFolderView/IFolderView2 均为 S_OK，可读取当前50个图标及坐标，自动排列关闭；QI(IShellFolderView) 返回 0x80004002 E_NOINTERFACE。该客户端不能使用候选 RemoveObject 路径，未调用任何隐藏、移动、刷新或恢复操作。探针结果不证明所有实现路线都不可行，也不证明恢复能力；它说明当前候选缺少可用的逐项隐藏接口，后续方案仍需验证。构建和运行退出码均为0，构建0警告0错误。

## 安装包与初步资源测量

- 压缩体验包约 72.6 MiB；解压后的自包含程序约 171.3 MiB，含运行库，不需要额外安装 .NET。
- 单屏 1920×1080 / 125%，65 个入口、2 个分组，两进程（界面与恢复保护），预热 10 秒后各采样约 31.6 秒。
- 两次正常路径的平均合计私有内存分别约 179.1 和 194.3 MiB；第二次峰值约 241.9 MiB。合计工作集平均约 288.5～311.4 MiB。
- 整机归一化 CPU 平均分别约 0.028% 和 0.871%。采样期间没有隔离用户输入、壁纸和系统后台活动，不能据此宣称稳定上限。
- 含截图的 UI 自检平均私有内存约 203.4 MiB，不混作正常运行结果。GPU/显存、长时间稳定性和电池续航未测。
- 当前尚未达到最初单屏私有内存 150 MiB 的优化目标，CPU 两次采样有明显波动。该版本供功能与视觉体验，轻量化目标仍待优化，不能宣称性能验收全部完成。

## 明确未验证的项目

- 当前设备只枚举到一块活动屏幕，真实外接屏插拔、拖动中断屏、睡眠/合盖、主屏切换、换接口及相同型号双屏尚未实测；纯逻辑和取消事件策略已有测试。
- Win+D、完整桌面键盘交互、Windows 右键原生菜单兼容性及多种壁纸模式需用户体验。
- 已验证隔离安装后的程序启动和正式卸载清理器，未在真实用户账户执行开始菜单/HKCU 安装注册、Windows 设置发起卸载、升级和卸载后重启全过程。
- 其他 Windows 11 build、Windows 10、ARM64 与 Insider 均未认证。
- 程序未签名；系统自动生成的安全、运行和安装记录不属于本工具可保证清理的范围。

## 实施取舍与后续建议

- 空仓库没有提交基线，采用用户指定工作副本内的独立功能分支，没有直接在 main 修改；未创建额外 worktree。
- 遵守用户文件规范，将临时工作台、SDK 和证据放 `.codex/`，正式文档放 `docs/`，不使用技能默认的 `.superpowers` 或 `docs/superpowers`。
- 根据最新授权缩减为分组 MVP，后续模块留待体验后决定。
- 发布采用目录式自包含包，避免单文件原生库提取缓存；安装清单用于有边界的卸载。
- 分组偏好与临时呈现位置分离；跨配置租约等待交接，取消拖动与重建期间禁止保存。
- 非阻塞建议：守护进程失败目前返回明确非零退出码，由主程序检测；可进一步增加守护失败诊断日志。
