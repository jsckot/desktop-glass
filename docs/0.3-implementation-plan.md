# Desktop Glass 0.3 Implementation Plan

日期：2026-10-23。基线 `2d93b56`，分支 `feat/desktop-groups-mvp`。
设计：[0.3-design.md](0.3-design.md)。用户已确认继续处理，并补充参考 Apple Liquid Glass 的整体验证与样式优化。

**目标：** 交付单 EXE 安装器、可选安装目录、空桌面首启、分组管理面板与统一玻璃外观。
**架构：** 维持 C#/WPF 与独立桌面宿主，新增管理面板；Workspace v2 保存逐组显示状态，v1 迁移时全部关闭；Inno Setup 负责安装负载与卸载入口，程序负责退出和恢复前置检查。
**执行：** 主代理单代理实施，最后独立只读 Reviewer。根会话模型 gpt-6.1-sol（可信 Hook 本回合初始值），档位 Max（用户确认的会话策略基准），Reviewer 同模型、high；不派发实施代理。

## 全局约束

- 只本地阶段提交，不 push/PR/合并；保留 tests/Verify-Windows.ps1 的已有修改。
- 临时文件、工具、预览及安装测试均在项目 .codex；正式文档在 docs。
- 不覆盖真实分组配置，不为视觉验证收纳用户现有文件，不擅自改 Windows 设置。
- 已有稳定身份、属性位合并、恢复日志和强退守护继续生效。
- 自选路径不允许未知目录覆盖或递归删除未知内容；卸载前恢复失败必须保留责任。
- 新版只对本机 Windows 11 x64 定向验证；不以逻辑测试替代真实多屏测试。

## 审查重点

- v1 的备份恢复和迁移保存失败不能丢旧分组，也不能先隐藏原图标。
- 隐藏组、缺屏组的引用不参与收纳；显示状态保存失败恢复原租约。
- 重复启动应聚焦已有面板，关闭面板不等于退出软件。
- 安装到中文/空格目录、取消、升级路径变化和卸载失败不影响未知文件。
- 玻璃降低白色覆盖后仍能读清图标名称；高对比度环境提供实底。
