# Desktop Glass 0.4.1 Implementation Plan

日期：2026-10-24。基线 `97661a3`，沿用 `feat/desktop-groups-mvp`。修复鼠标离开后名称、图标与边框消失的问题；不扩大文件管理范围。

## 根因与方案

实际屏幕对照已复现：同一 WPF HWND 上的全幅 HostBackdrop Composition visual 覆盖 WPF 内容。将该 visual 的透明度设为零，文字及边框立刻恢复；禁用材质也恢复。窗口 Visible/Opacity、离屏渲染和 PrintWindow 不能验证系统最终合成。

自有窗口原型验证：让 HostBackdrop 位于独立背景 HWND，WPF 前景使用透明客户区，两者相邻排列，文字、图标与实时背景同时可见，失活后仍保留。正式实现仅管理本进程窗口，不设置 Explorer owner，不注入、不截图模拟、不添加持续轮询。背景层禁止激活和接收输入，跟随前景的物理坐标、裁剪、层级、显示与销毁；不能留下残影或独立任务栏入口。

参考 DeskBox 固定提交 `1fdf0bd9f84affe889318173a7f3141843c79604` 的常驻紧凑入口及独立前景/材质原则，未复制 GPL 源码。原有 144 DIP、名称、最多四图、12 DIP 轻圆角及悬停规则保持。双 HWND 是本项目 WPF 合成限制的处理方式，不是 DeskBox 的折叠实现。

## 风险及边界

高风险：新增自有背景窗口生命周期与桌面层级协作，改变原生窗口边界。需要独立只读审查；根会话用户确认 GPT-6 Astra / Max，已验证本回合 Hook 初始模型 gpt-6-astra，子代理按策略采用 gpt-6.1-sol/high，不进一步委派。

- 收起、快速反向、拖动/改变尺寸：两层位置及裁剪一致，紧凑入口像素可见。
- 非激活、普通窗口遮挡：玻璃与内容保持同层级，其他应用正常遮挡。
- Hide/Show、最小化、关闭：无独立背景残留，不复活已关闭组件。
- 多分组、反复启停及初始化失败：资源独立释放，缺能力时使用可辨认中性底色。
- 原生桌面鼠标、文件属性租约、用户布局及显示器偏好保持原契约；物理多屏仍需真机后续验证。

## 工作包与验收

1. 新增 `tests/DesktopGlass.CompositionTests/`，链接生产组件并在自有彩色窗口上检查实际屏幕像素。先记录旧实现失败；以标题墨色、图标及边框存在为断言，不能只断言 HWND 可见。
2. `WindowBackdrop.cs` 及必要专用辅助类管理隔离材质 HWND；`DesktopLayer.cs` 将背景视为同组件辅助层；`WidgetHost.cs` 在物理定位/裁剪完成后同步。保持现有 Enable/Disable/Result 入口，新增同步与辅助 HWND 映射仅用于生命周期集成。
3. 回归真实像素、展开/收起、几何变化、隐藏/恢复、多实例释放、桌面层级、现有悬停/外观/布局检查。产物及日志置于 `.codex/tmp/0.4.1/`，不触碰真实文件租约或 Windows 设置。
4. 独立审查最终差异与证据，关闭必修项。更新版本及安装器，生成 0.4.1 EXE，校验发布产物并本地中文提交；不 push/PR/合并。保留用户已有 `tests/Verify-Windows.ps1` 未提交修改。
