# Desktop Glass 0.2.0

Windows 原生桌面的玻璃分组工具。本轮提供 `0.2.0-win-x64` 安装体验版，首轮范围是独立分组组件与普通桌面项目收纳，不包含任务栏、系统文件夹或全系统图标美化。

本机验证环境为 Windows 11 26H2 / 26300.9711 x64、2560×1380 工作区、125% 缩放。用户已确认组件可见、标题拖动及组件外原生操作正常；真实测试快捷方式拖入后，组内出现图标，原桌面图标消失。完整证据和未测范围见 [验收记录](acceptance.md)。

## 安装体验

1. 若正在使用旧版，先从旧程序托盘或菜单选择“恢复桌面并退出”。
2. 将 `DesktopGlass-0.2.0-win-x64.zip` **完整解压**到一个文件夹；不要只取出其中的 `.exe`。
3. 双击解压目录中的 `DesktopGlass.exe`，在安装询问中选择“是”，安装到当前用户并启动；选择“否”则仅运行本次。
4. 安装后可从开始菜单启动 Desktop Glass；需要卸载时，从开始菜单使用“卸载 Desktop Glass”，或使用 Windows 的已安装应用入口。卸载会先尝试恢复收纳项目，恢复未完成时保留日志并停止清理。

安装无需管理员权限，也无需预先安装 .NET。发布采用包含运行库的目录式自包含包；整个解压目录共同构成安装来源。

发布目标：`.codex/artifacts/DesktopGlass-0.2.0-win-x64.zip`，对应目录 `.codex/artifacts/desktop-glass-0.2.0-win-x64/`。构建、安装验证、包体积及已知限制见验收记录。

## 收纳前确认 Windows 设置

收纳要求下列设置均关闭；程序以桌面实际隐藏显示设置为准，无法确认时拒绝收纳，不会替你修改设置：

- 资源管理器“查看 → 显示 → 隐藏的项目”：关闭。
- 桌面右键“查看 → 自动排列图标”：关闭。

任一条件不满足或无法确认时，程序会说明原因并拒绝收纳，空分组组件仍可使用。若希望继续显示隐藏项目，可以保留自己的设置，并暂不使用收纳。

若此前已开启“隐藏的项目”，体验收纳前请手动关闭；退出后可按个人习惯重新开启。

## 使用方式

1. 启动后显示独立的玻璃分组，组件之外继续使用 Windows 原生桌面。
2. 从桌面把普通文件、文件夹或快捷方式拖入分组。程序保存引用，临时设置该项目的 Hidden 位，文件位置和内容保持原样。
3. 双击组内图标打开原对象；右键“移出分组”恢复该图标。组内拖拽可排序，也可以在分组间移动。
4. 拖动标题移动分组，拖动右下角调整大小；“⋯ → 名称与玻璃外观”可调整名称、玻璃浓度和圆角。
5. 从组件菜单或托盘新建分组、锁定布局或退出。布局锁定限制移动和缩放，保留内容管理。
6. 移出项目、删除分组或退出时，恢复本程序修改的 Hidden 位和收纳前坐标。删除分组不会删除文件。

恢复失败时会保留恢复日志并提示原因；请保留提示中的配置目录和日志，不能把日志删除当作已恢复。

## 当前边界

- 收纳限于当前用户或公共桌面的直接子项，并需具备相应属性写入权限。回收站、此电脑等虚拟入口、重解析入口及其他路径不在本轮收纳范围。
- 租约期间按稳定文件身份恢复。已收纳对象改名、删除或被替换后，旧引用可能失效；打开或移组会核对身份并提示先移出旧引用、再重新拖入。永久分组仍使用路径引用，跨启动的同路径替换不是持久文件身份跟踪。
- 外屏缺失时使用临时呈现位置，不覆盖保存的显示器与布局；真实双屏热插拔、混合 DPI 和睡眠恢复尚未实测。
- Win+D、多种壁纸模式、其他 Windows 版本及长时间资源占用未完成验证。0.1.0 的性能数据不能代表 0.2.0。
- 玻璃使用静态壁纸模糊采样和细高光，无常驻动画，不承诺实时背景折射。

## 旧版说明

0.1.0 的全屏接管方案不符合本轮要求，并出现过实际桌面不显示组件的问题。旧版离屏预览和结构检查不能证明真实显示正常；相关结果仅作为历史记录保留，不作为 0.2.0 的 UI 或性能验收。体验时请使用本次 `0.2.0-win-x64` 包。

## 开发与验证

构建需要 Windows x64 和 .NET 10 SDK：

```powershell
./scripts/Build.ps1 -Dotnet <dotnet.exe 路径>
```

领域测试：

```powershell
dotnet run --project tests/DesktopGlass.Tests -c Release
```

新版的属性租约、控制器和清理状态有独立诊断入口。真实桌面恢复诊断只允许显式指定、所有权校验通过的专用测试快捷方式，不用于任意用户文件。旧版 `--smoke`、`--crash-test` 和 `--ui-test` 仍有历史全屏路径，不能替代新版验收；请按 [验收记录](acceptance.md) 中的新版证据区分。
