# Desktop Glass 0.3.0

Windows 原生桌面的玻璃分组工具。本版增加可选目录的 EXE 安装向导、分组管理面板、空桌面首启与临时前景模式。范围仍为桌面分组，不包含任务栏或全系统图标替换。

## 安装

1. 运行 `DesktopGlass-Setup-0.3.0-x64.exe`。
2. 向导默认选择当前用户的 `%LOCALAPPDATA%\Programs\DesktopGlass`，也可选择独立的新目录；已安装时会预填上次目录。
3. 安装后打开管理面板，桌面不会自动创建示例分组。
4. 从 0.2 升级时保留原分组与布局，并暂停显示一次；在面板手动选择“显示”或“移到当前屏幕”。

安装无需预装 .NET 或管理员权限。后续可以从开始菜单启动，使用“卸载 Desktop Glass”或 Windows 的已安装应用卸载。卸载前会恢复收纳项目；恢复失败会中止并保留责任记录。更换安装位置失败时，先在当前安装位置重装完成修复，再更换目录。

## 使用

- 在管理面板点击“新建分组”，选择名称、屏幕与外观。后续启动恢复上次的显示状态。
- 将桌面的普通文件、文件夹或快捷方式拖入组件；双击图标打开，右键“移出分组”恢复原图标。组内支持排序和跨组拖动。
- 拖动标题移动，右下角调整大小，“⋯ → 名称与玻璃外观”调整浓度与圆角。布局锁定仅限制移动和缩放。
- 默认分组贴在桌面，普通应用会遮挡它。在面板或托盘选择“临时浮到应用前面”，需要时再“放回桌面”。临时层级不跨重启保存。
- 关闭管理面板会留在托盘；双击托盘再次打开。“恢复项目并退出”才会停止程序并恢复图标。
- 在面板隐藏或移除分组时，其原桌面入口也会恢复。移除分组不删除真实文件。
- 显示器暂离时，分组保留在面板中，不会堆到主屏幕；重新接回后按原显示意愿恢复。显式“移到当前屏幕”才改变屏幕与布局。

## 收纳条件

资源管理器“显示隐藏的项目”和桌面“自动排列图标”需关闭。程序检查实际桌面视图，不替你修改 Windows 设置；无法确认时拒绝收纳，空组件仍可使用。

收纳保留原文件路径与内容，仅临时设置 Hidden 位，退出时恢复本程序改动的属性及收纳前坐标。回收站、此电脑等虚拟入口、重解析链接及其他目录不支持收纳。租约期间核对稳定文件身份；永久分组仍按路径引用，不包含跨启动文件身份跟踪。

## 视觉与验证范围

桌面组件使用轻量壁纸模糊与细边缘；临时前景组件使用 Windows 的实时 Acrylic，能反映后面的窗口。系统在未激活、节能、远程会话等条件下可能采用系统回退材质；此版不实现物理折射或流体动画。应用原图标保持辨识度，程序 Logo、面板、滑杆和滚动条使用统一样式。

本机 Windows 11 26H2 / 26300.9711 x64、2560×1380 工作区、125% 缩放定向验证。真实双屏热插拔、混合 DPI、Win+D、其他 Windows 11 build 与长期资源指标尚未完成实测；不宣称全版本适配。当前结果及历史记录见 [验收记录](acceptance.md)。

## 开发

需要 Windows x64、.NET 10 SDK 和 Inno Setup 6.7+：

```powershell
./scripts/Build.ps1 -Dotnet <dotnet.exe 路径> -InnoCompiler <ISCC.exe 路径>
dotnet run --project tests/DesktopGlass.Tests -c Release
./tests/Verify-Installer.ps1 -PackageDir <发布目录> -InnoCompiler <ISCC.exe 路径>
```

安装器隔离检查不写真实安装登记、快捷方式或用户配置，所有测试负载放在项目 `.codex/`。正式安装包输出到 `.codex/artifacts/DesktopGlass-Setup-0.3.0-x64.exe`。

属性租约、控制器、清理、窗口生命周期和渲染另有独立诊断入口。历史全屏路径 `--smoke`、`--crash-test`、`--ui-test` 不作为新版原生桌面验收依据。

设计见 [0.3 设计](0.3-design.md)，进度见 [0.3 实施计划](0.3-implementation-plan.md)。
