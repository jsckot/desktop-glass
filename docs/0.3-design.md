# Desktop Glass 0.3：安装器、管理面板与玻璃分组设计

日期：2026-10-23。代码基线：`690f23e`，分支 `feat/desktop-groups-mvp`。状态：设计稿，待用户审核后制定实施步骤；尚未生成新版安装程序。

## 用户目标和已确认决策

- 用一个 `.exe` 安装包完成安装，预填安装目录，允许用户浏览或输入自己的目录。
- 首次安装只打开管理面板，不创建、显示任何桌面分组，不收纳桌面项目。
- 旧版升级保留已有分组及内容，但先全部暂停显示；用户在面板中逐个恢复。
- 用户确认：日后启动恢复上次显示的分组，不需要每次手动打开。
- 从面板新增分组，并能管理名称、外观、所在屏幕、显示状态和移除。
- 参考 DeskBox 的独立管理入口与轻量材质方向；分组视觉改为通透玻璃，设计一版自己的 Logo。
- 保留现有原生桌面交互、只收录引用、退出恢复属性与原坐标等约定。

## 方案选择

| 方案 | 影响 |
| --- | --- |
| 推荐：保留 C#/WPF，加入 Inno Setup 安装器和管理面板 | 延续已验证的分组与恢复能力，标准安装向导负责路径选择、程序文件和卸载登记 |
| 自制一个包含负载的 WPF 安装器 | 能完全定制安装界面，但需要自行继续承担解包、安装回滚和卸载维护，重复已有安装器能力 |
| 改成 WinUI 3 并重做桌面宿主 | 更接近参考项目技术栈，但会扩大本轮范围，原生宿主与恢复必须重新验证 |

采用推荐方案。用户接触的文件是 `DesktopGlass-Setup-0.3.0-x64.exe`，安装后运行 `DesktopGlass.exe`；不再要求解压 ZIP 或由主程序弹出安装询问。

## 安装、升级和卸载

- 默认目录：`%LOCALAPPDATA%\Programs\DesktopGlass`；安装向导始终显示目录页，可手动选择如 `D:\Apps\DesktopGlass` 的可写目录。
- 使用当前用户级安装。安装器提前检查目录、写入权限及已有归属；不静默覆盖未知目录，不靠强制提权绕过路径错误。
- 安装结束默认打开管理面板，创建开始菜单入口；不额外创建桌面快捷方式，不默认开机启动。
- 新版检测已登记的旧版安装位置，先停止旧实例并确认逐项/历史恢复已完成，再升级；选择不同路径时必须清楚展示迁移来源和目标，有归属校验的旧程序清理完成后才切换入口。
- 安装位置和用户配置位置分离。用户分组配置仍位于 `%LOCALAPPDATA%\DesktopGlass`；自选安装目录不得使程序反复认为自己尚未安装。
- Windows“已安装的应用”和开始菜单均提供卸载入口。卸载前确认主程序退出、所有恢复责任完成，再清理软件配置和安装器登记的文件；恢复失败必须终止卸载，保留程序和日志供恢复。
- 安装中断、路径含中文/空格、文件占用、未知文件和目录链接需要专门验证；不递归删除用户自行放入的其他内容。
- 本轮仍以本机 Windows 11 x64 为交付目标，不承诺所有 Windows 版本已验证。

## 管理面板和启动行为

主窗口约 940×640 DIP，采用标准窗口交互。左侧为品牌和“桌面分组/外观/关于”，主区域使用紧凑列表，顶部固定“新建分组”。关闭面板后软件留在托盘，双击托盘或再次启动打开已有面板；只有明确退出软件才恢复全部收纳项并结束进程。

```text
┌─────────────────────────────────────────────────────┐
│ Logo  Desktop Glass                         ─ □ ×   │
├─────────────┬───────────────────────────────────────┤
│ 桌面分组     │ 桌面分组                  ＋ 新建分组   │
│ 外观        │                                       │
│ 关于        │ 首次：添加你的第一个桌面分组             │
│             │ 从桌面拖入快捷方式或文件，随时原位恢复。   │
│             │              [新建分组]                │
│             │                                       │
│             │ 已有：名称 / 项目数 / 显示器 / 显示开关   │
│             │       编辑外观 · 移到当前屏幕 · 移除      │
└─────────────┴───────────────────────────────────────┘
```

- 首次安装：列表为空，桌面不变。点击新建后输入名称、选择当前可用屏幕，确认才创建并显示一个空分组。
- 新增分组不预填示例项目，不按类别自动生成多个分组。默认约 320×240 DIP，可在面板调整；原有分组尺寸保留。
- 隐藏分组时必须释放其中的收纳项并恢复原位置；隐藏后不再自动收纳其引用。显示时才重新验证条件、取得租约并收纳。
- 面板把旧分组标为“待显示”；用户可显示到原屏幕，或明确选择“移到当前屏幕”。不需要删除旧分组来摆脱占满桌面的状态。
- 屏幕暂离时，分组仅在面板列出，不在主屏平铺大卡片。保留原屏幕与几何偏好；对应屏幕恢复后，只有上次启用的分组恢复显示。
- 暂离分组没有实际可见组件时不隐藏对应原图标；重新显示后的坐标由新的收纳会话记录，不覆写未收纳项目位置。
- 旧分组的自动显示切换只发生一次；后续重启根据保存的状态恢复，不重复重置。

## 配置兼容与事务边界

- 工作区使用版本 2，增加每组的持久显示意愿。读取版本 1 时验证原数据，迁移副本中全部设为不显示；保存成功前不创建组件或隐藏文件。
- 保留旧版配置备份，迁移保留分组 Id、名称、顺序、图标引用、显示器、坐标和外观；不通过清空配置处理兼容问题。
- 未知版本或无效配置继续明确报错，不以空工作区掩盖损坏；版本 2 不允许旧版程序直接覆盖。
- 显示、隐藏、移屏与新增操作沿用持久化事务。保存失败或收纳失败时恢复工作区与租约；恢复失败保留责任并进入现有错误处理。
- 仅恢复已启用、当前确实可呈现分组的收纳项，禁止启动时遍历所有旧分组并隐藏其原图标。

## 视觉与 Logo

参考目标以 `Tianyu199509/DeskBox` 为准：独立管理入口、原生桌面格子、轻量层次。参考交互与材质方向，自行实现本项目的代码和品牌。

- 色板：深墨 `#172D3D`，次级文字 `#5F7482`，冷白 `#F1F7FA`，冰蓝 `#8DCDE4`，主操作蓝 `#357FA1`。控件状态保证文字清楚可读。
- 字体：中文采用 Microsoft YaHei UI，英文和数字 Segoe UI；主标题 24、分组标题 14、正文 13、说明 11 DIP。
- 分组减轻现有大面积白色遮罩，保留较多壁纸色彩；细高光边缘、轻内阴影、20 DIP 圆角与适度模糊共同表达玻璃厚度。透明浓度、尺寸和圆角仍可调整。
- 正常空分组缩小标题区和空态提示，去掉突兀的大加号；内容图标使用原图标，不改变应用辨识度。
- Logo 概念：两片错位叠放的圆角玻璃片，前片有一个简洁的收纳格，冰蓝与白色高光；在 16/24/32/48/256 像素下检查辨识度。源图采用矢量，导出 ICO 用于安装器、程序、开始菜单和托盘。
- 主面板使用稳定浅色背景，重点留给桌面组件。默认桌面层使用静态壁纸采样；用户追加确认的临时前景模式使用 Windows 标准 Desktop Acrylic，关闭壁纸层，不将其称为物理折射；不新增常驻流体动画。
- 临时前景仅本次运行有效，可在面板和托盘切换，重启默认回到桌面层；重建自己的窗口，不修改 Explorer 样式或文件租约。同屏移动、缩放和取消只更新原 HWND，避免松手闪烁。

## 验收与质量门禁

本轮改变配置契约、收纳启停和安装/卸载边界，按高风险处理。由主代理按现有单代理实施方式完成，最终使用未参与实施的只读 Reviewer；根模型和强度遵循本会话 AGENTS 规则。

1. 新配置启动零分组、零桌面属性变更；旧配置迁移后所有分组保留但桌面零组件。
2. 新建、显示、隐藏、移屏及重启能恢复保存状态；保存/租约故障不丢引用和恢复责任。
3. 缺屏只在面板提示，接回恢复；不修改原显示器坐标，显式移屏才改变归属。
4. EXE 安装向导始终可选路径；默认路径和含中文/空格的自选目录安装均可正常启动，不再出现安装询问。
5. 隔离验证升级、取消、中断、路径拒绝和卸载；卸载遇到未完成恢复时保留文件与日志。
6. 在本机查看真正的安装向导、面板空态和一组玻璃组件；验证桌面外部右键/框选、正常与强退恢复。
7. 运行受影响领域/事务/安装诊断、Release 构建、独立审查和安装包一致性检查；未做的物理双屏、性能项目明确记录。
8. 分阶段中文本地提交，不 push、不创建 PR、不提交 `.codex/`。
