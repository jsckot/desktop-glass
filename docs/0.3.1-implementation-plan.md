# Desktop Glass 0.3.1 Implementation Plan

日期：2026-10-23。基线 `98c64fb`，分支 `feat/desktop-groups-mvp`。承接 0.3 已确认的液态玻璃设计及本轮四项用户反馈。

## 目标与设计

优化组件菜单、品牌 Logo、管理面板和外观编辑器；拖动玻璃浓度及圆角时即时预览桌面组件，保存后持久化，取消或关闭恢复已保存外观。最大圆角保持四角一致、边框同心，缩放标记不穿过弧线。

沿用 C#/WPF、原生桌面宿主和现有系统材质，不增加动画常驻开销。视觉以雾白 `#F4F7FB`、深海蓝 `#122C49`、蓝灰 `#667991`、清透蓝 `#397FC4`、冰青 `#8EDDE7` 为基调；微软雅黑 UI 正文，清晰字号层级。Logo 使用深蓝玻璃底与折光叠片，避免简单网格符号。面板左侧保留清晰导航，主区以标题、工具条、分组列表组织内容，精简重复说明和操作。菜单使用圆角浮层、独立图标列、分隔线与键盘焦点。

现有 WPF 控件系统内统一视觉比引入新 UI 框架更适合本次增量更新；保留当前液态玻璃方向，不改桌面交互模型。

## 约束与审查重点

- 不改变文件收纳、恢复责任、安装路径、配置版本；不操作用户实际桌面项目及真实分组配置。
- 保留 `tests/Verify-Windows.ps1` 已有工作区状态；不 push/PR/合并。
- 临时证据仅 `.codex/tmp/0.3.1/`，安装包沿用 `.codex/artifacts/`。
- 外观预览不能写入配置、重建窗口、改变租约；取消、保存失败、显示/隐藏、跨屏重建和退出必须正确恢复或清理预览。
- 不以旧草稿覆盖编辑期间的布局或收纳变化；多个分组编辑互不干扰。
- 最大圆角、0 圆角和 100%/125%/150% DPI 的几何一致；高对比度和键盘可访问性保留。
- 实时预览改变编辑器—控制器—原生宿主边界，按高风险执行，需独立只读审查。
